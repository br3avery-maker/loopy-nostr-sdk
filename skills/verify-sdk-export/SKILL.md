# Verify, package and hand off

Run `npm run verify`, `node examples/offline-publish-plan.js`, `python3 -m unittest discover -s tests -p 'test_*.py'`, `npm pack --dry-run`, then build ZIP/tarball with code, types, docs, skills, workflows, examples, tests and provenance. Re-extract into a fresh directory, rerun tests, and compare SHA-256. The source collection generated by `scripts/source_collection.py` is a separate exact-byte, content-addressed donor archive: verify restore, source manifests, skipped entries and permissions separately.

Preserve final files in the requested durable Library/Drive workspace, update IC Live inventory and link verification receipts. Stop and report any failed gates or unverified host claims; no public GitHub/Nostr publishing without distinct authorization and license check.
