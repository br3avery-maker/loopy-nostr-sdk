# Capability provenance

See `provenance/repo-capabilities.json` for the adopted and already-covered source contracts. The internal donor inventory and unrelated repository list remain private. The runtime API retains source-derived moderation, media identity, signed event handling, archival CDC, backup/restore and relay planning. The public build supplies no personal moderation lists; pass explicit policy arrays. Run `python3 validation/verify_repo_audit.py` to verify the listed runtime contracts. Full application, device, signer and live publishing tests remain separate.
